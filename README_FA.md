## 🌟 معرفی پروژه

**PuLaExPeLoReR** یک محیط دسکتاپ تحت وب (Web OS) و فایل اکسپلورر ابری همه‌کاره، فوق‌العاده سبک و پرسرعت برای سرورهای لینوکس و انواع VPS است.

این سیستم با استفاده از **FastAPI، وب‌سوکت، xterm.js و پایگاه‌داده داخلی SQLite** توسعه داده شده و بدون تحمیل هرگونه بار پردازشی سنگین یا نیاز به نصب محیط‌های دسکتاپ لینوکسی (مانند XFCE, GNOME یا سرورهای VNC)، تجربه‌ای روان، مدرن و مشابه ویندوز ۱۱ را درون مرورگر وب در اختیار شما قرار می‌دهد.

---

## ✨ ویژگی‌ها و قابلیت‌های کلیدی

- 🪟 **رابط کاربری مدرن با استایل ویندوز ۱۱:**
  - افکت شیشه‌ای مات (Glassmorphism / Acrylic).
  - پنجره‌های شناور با قابلیت جابجایی نرم و بدون باگ (با لایه اختصاصی جلوگیری از گیر کردن موس).
  - تغییر ابعاد پنجره (Resize) از گوشه پایین سمت راست.
  - بزرگ‌نمایی کامل (Fullscreen / Maximize) با کلید اختصاصی یا دابل‌کلیک روی هدر پنجره.

- 📁 **فایل اکسپلورر پیشرفته سرور:**
  - منوی کلیک‌راست هوشمند شامل بیش از ۱۰ ابزار کلیدی.
  - فشرده‌سازی فایل‌ها و فولدرها به فرمت `.zip` و استخراج سریع (`unzip`).
  - ویرایش سطوح دسترسی فایل‌ها (`chmod`).
  - تکثیر فایل (Duplicate)، تغییر نام (Rename)، دانلود مستقیم و آپلود با کشیدن و رها کردن (Drag & Drop).
  - نوار آدرس و ناوبری سریع در دایرکتوری‌های سیستم‌عامل.

- 💻 **ادغام کامل VS Code واقعی (Visual Studio Code):**
  - اجرای رسمی هسته `code-server` داخل پنجره دسکتاپ.
  - امکان نصب تمام افزونه‌ها (Extensions)، تغییر تم، گیت و شرت‌کات‌ها.
  - کانفیگ و هدایت خودکار به پورت اختصاصی مجزا (`port + 1`).

- 📟 **ترمینال زنده و تعاملی لینوکس:**
  - شل واقعی Bash متصل به PTY از طریق وب‌سوکت.
  - باز شدن مستقیم در دایرکتوری `/root` با نام کاربری و دسترسی کامل.
  - پشتیبانی از تمام دستورات، نرم‌افزارهای ترمینالی (`htop`, `nano`) و رنگ‌ها.

- ⚙️ **مرکز کنترل و شخصی‌سازی (Settings):**
  - گالری والپیپرهای 4K (بلوم تاریک، سایبرپانک، توکیو نایت، مشکی امولد، فضای عمیق) و امکان افزودن لینک تصویر دلخواه.
  - ۵ رنگ اکسنت سیستم (آبی، زمردی، بنفش، نارنجی، قرمز).
  - تنظیم میزان تاری شیشه‌ها (Blur).
  - تغییر چیدمان تسک‌بار بین حالت ویندوز ۱۱ (وسط‌چین) و ویندوز ۱۰ (چپ‌چین).
  - تغییر سایز فونت ترمینال (۱۳ تا ۱۸ پیکسل).
  - تغییر رمز عبور امن با هش SHA-256 ذخیره‌شده در SQLite محلی.

- 📊 **تسک منیجر (Task Manager):**
  - مانیتورینگ بلادرنگ و زنده میزان مصرف CPU، رم سرور و فضای دیسک روت.

- 🔒 **صفحه قفل امنیتی:**
  - محافظت از دسترسی به محیط دسکتاپ با رمز عبور در بدو ورود.

## ⚡ راهنمای نصب و راه‌اندازی سریع

### ۱. کلون مخزن و اجرا:
```bash
git clone https://github.com/PuLaTeam/PuLa-explorer.git
cd PuLa-explorer
chmod +x pula.sh
./pula.sh
```

### ۲. انتخاب پورت:
اسکریپت به صورت تعاملی پورت مورد نظر شما را می‌پرسد (پیش‌فرض: `8586`):
- آزاد بودن پورت اصلی و پورت بعدی (`PORT + 1`) را با سوکت پایتون اعتبارسنجی می‌کند.
- پورت‌ها را به صورت خودکار در فایروال لینوکس (`ufw` / `iptables`) باز می‌کند.
- آی‌پی عمومی سرور را پیدا کرده و لینک‌های مستقیم وب‌دسکتاپ و ویسکود را چاپ می‌کند.

### ۳. اطلاعات ورود پیش‌فرض:
- **رمز عبور:** `admin` *(از طریق نرم‌افزار Settings قابل تغییر است)*


### 4. کامند پولا
- در هر جایی از ترمینال بنویسید ```pula``` تا پنل اکسپلورر برای شما باز شود کارایی ها: تغییر رمز و پورت ران کردن و استاپ
